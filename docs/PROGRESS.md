## M2 — PGN, games, library: done

Done:
- `glyph_core/pgn/`: `parsePgn` / `parsePgnBytes` (+ `*Async`, `Isolate.run` above 100 KB): BOM + CRLF/CR normalisation, own multi-game splitter (state machine: no blank line needed between games, tracks `{}` with nesting, `;`, `%` lines, variations; drops share-text preambles), dartchess parse, mainline only, every move replayed (canonical SAN, UCI, FEN after, `%clk`, `%eval`, comment text), `PgnParseResult` = `PgnOk` / `PgnPartial(skipped)` / `PgnFailed(issues)`; `PgnIssue` has kind, 1-based game index, ply, SAN, move number. Variants other than standard/Chess960 rejected ("Crazyhouse games aren't supported."), `[SetUp][FEN]` and Chess960 handled. Caps with tests: 2 MB (UTF-8 bytes), 500 games, 1000 plies, 4 KB comments.
- `glyph_core/game/`: `Game`, `Ply`, `PlyEval`, `PositionCursor` + `MainlineCursor`, `detectUserSide` (case-insensitive, site-aware).
- `glyph_core/pgn/pgn_export.dart`: `exportAnnotatedPgn` (labels and evals passed in; NAGs $3 $1 $6 $2 $4, Miss = $2 + `{ Miss }`, `[%eval]`, `[%clk]`, `[Annotator "Glyph"]`).

- PGN golden vectors in `packages/glyph_core/test/vectors/pgn/` (real data from the M0 samples where possible; synthetic ones regenerated by `packages/glyph_core/tool/gen_pgn_fixtures.dart`): chess.com download, chess.com app share text (with preamble), lichess API export, lichess app share, 50-game file, 3 games without blank lines, Chess960 + FEN (real lichess game with castling), CRLF + BOM, variations + NAGs + nested braces, illegal move (single and in multi-game), crazyhouse (single and mixed), 0-move game; 2 MB + 1 byte, 501 games, 1001 plies and 4 KB comments are built in the tests. Notes for M3 / M4:
- Repositories are `Future`-based interfaces over synchronous sqlite3 on the UI isolate. Per-ply writes are tiny; if M3 profiling shows jank, open the DB in a worker isolate behind the same interfaces.
- `Ply.uci` is dartchess form (castling = king takes rook, e.g. `e1h1`), `Ply.fen` is the FEN after the move, `Game.startFen` the start; `Game.startPosition()` and `MainlineCursor` give `Position`s. `Ply.eval` / `clockMs` come from the PGN comments (White POV evals).
- `exportAnnotatedPgn(game, labels: {ply: MoveLabel}, evals: {ply: PlyEval})`; plies are 1-based.
- `OpeningBook.annotate(game)` returns `bookPlies` (contiguous prefix) and the deepest named opening. chess-openings only lists named positions, so an ordinary Ruy Lopez leaves the prefix after 3...a6 (4.Ba4 Nf6 are unlisted) while a later move is named again; if that is too stingy for the Book label, extend the asset with intermediate positions in M4 (the SHA test then needs updating).
- `SettingsKeys.lichessUsername` / `chessComUsername` feed `detectUserSide` at import time; the Settings UI for them is still to come.
- `GameRepository.setUserSide` exists for the per-game override (UI in M5).
